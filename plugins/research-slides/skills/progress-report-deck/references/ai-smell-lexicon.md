# AI 臭い言い回しのリスト（研究発表向け）

スライドと構成案の文言を仕上げるときに見る。生成した文章にありがちな「盛った・回りくどい・中身の無い」言い回しを、研究室の発表で通じる普通の言葉に戻すためのリスト。

考え方の元は carnot-tech/jinba-consulting-pptx-skill（MIT）の ai-smell-lexicon。コンサル資料向けの語を外し、研究発表で問題になる語に入れ替えてある。

## まず削る

- **装飾的な強調は削る**。「非常に」「極めて」「大幅に」は、数値があれば数値で言う（「大幅に改善」→「誤差が 12% 減った」）。数値が無いなら強調の根拠も無い
- **評価語は結果で裏づける**。「有効性を示した」「優れている」は、何と比べて・どの指標で・何回の試行で、が同じスライドにあるときだけ使う
- **言い過ぎを直す**。「保証した」→「確認した」、「同等」→「ほぼ同等」（数値がわずかに負けているとき）、「解決した」→「改善した」（残る課題があるとき）
- **未検証のことを言い切らない**。期待される性質と実験で示したことを混ぜない（「〜が期待される」は未検証と分かる形なので可）

## 置き換えの例

| 分類 | 避ける言い回し | こう書く |
|---|---|---|
| 空虚な強調 | 非常に／極めて／圧倒的に／飛躍的に／劇的に | 削る。差は数値で示す |
| 誇張 | 画期的な／革新的な／抜本的な／〜と言っても過言ではない | 削る。新しさは「従来は〜できなかった」と事実で書く |
| 回りくどさ | 〜することが可能／〜を行うことができる | 〜できる／〜する |
| 名詞化 | 〜の実現を図る／〜の向上に寄与する／〜を推進する | 〜を実現する／〜が上がる／〜を進める |
| 受け身の名詞化 | 〜の改善が図られた | 〜を改善した |
| カタカナ盛り | シームレスに／ソリューション／ブラッシュアップ／インサイト | なめらかに／手法／改良／分かったこと |
| 網羅の言い訳 | 包括的に／多角的に／総合的に検討 | 何を検討したかを列挙する |
| 先送り | 今後検討してまいります／詳細は別途 | 今後の課題に「何を・いつまでに」を書く。書けなければ消す |
| 自己美化 | 鋭意取り組んだ／邁進する | 削る |
| 枠組みの露出 | 背景・課題・解決策（見出しの羅列） | 中身を表す見出しにする |
| ダッシュ連結 | A — B | 「：」「（）」、または2つに分ける |
| 接続詞の連打 | また、さらに、加えて、そして | ほとんど消せる。箇条なら要らない |

## 研究では普通に使ってよいもの（チェックしない）

- 「〜と考えられる」「〜と推測される」（解釈であることを示す正当な表現）
- 「〜が期待される」（未検証と分かる形）
- 「頑健（ロバスト）」「最適」「有意」は専門用語として使うとき。ただし「有意」は検定をしたときだけ
- 「様々な」は条件を列挙できるなら列挙した方がよいが、禁止はしない

## 機械チェック用（check_deck.py が読む）

1行1語。`re:` で始まる行は正規表現。`=>` の後は置き換えの案（表示用）。WARN を出すだけなので、文脈上正しければ残してよい。

```words
非常に => 削るか数値で
極めて => 削るか数値で
圧倒的 => 削るか数値で
飛躍的 => 削るか数値で
劇的 => 削るか数値で
画期的 => 削る（新しさは事実で）
革新的 => 削る（新しさは事実で）
抜本的 => 削る
過言ではない => 削る
re:することが(可能|できる|できます) => 「〜できる」
re:を行うことが(可能|できる) => 「〜できる」
re:の(実現|向上|推進)を図 => 動詞で書く
re:に寄与(する|した|します) => 「〜が上がる／下がる」と結果で
re:が図られ => 「〜した」
シームレス => 具体的に
ソリューション => 手法
ブラッシュアップ => 改良
インサイト => 分かったこと
re:(包括|多角|総合)的に(検討|評価|分析) => 何を検討したか列挙
re:今後(検討|対応)して(まいり|いき)ます => 何を・いつまでに
詳細は別途 => 中身を書くか補足スライドへ
鋭意 => 削る
邁進 => 削る
re:\s[—―]\s => 「：」か括弧
```
